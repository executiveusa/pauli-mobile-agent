# Device Evidence

This directory stores local verification output generated by `npm run verify:android-device`.

Generated reports are intentionally ignored by Git because they may contain device metadata. Review and redact evidence before attaching it to a pull request or issue.

The verifier:

- requires Node, npm, and ADB;
- requires exactly one authorized Android device;
- records model, Android version, SDK level, ABI, and build fingerprint;
- hashes the ADB serial rather than storing it directly;
- does not claim an APK build, QVAC inference, encryption, or production readiness.

Never commit device serials, personal files, health records, screenshots, credentials, signing keys, or unredacted captures.
